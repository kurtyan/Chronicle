# 项目制使用说明

方向（Area）管理长期责任与关注领域，里程碑（Milestone）管理阶段成果或持续跟踪事项。Project 是模块名称，数据层没有第三层 Project 对象。

## 建立和推进

1. 从导航进入「项目」，新建方向，再在方向下建立里程碑。
2. 阶段型里程碑填写目标和完成标准；持续型用于长期实践和周期回顾。可以逐步补充 Task，不必在开始时拆完全部工作。
3. 在 Board 草稿、Task 详情或里程碑详情选择主里程碑。每个 Task 最多一个主里程碑，方向由它所属的里程碑确定。Board 草稿填写后点击「保存任务」，也可用 Mac 的 `⌘Enter` 或其他平台的 `Ctrl+Enter` 保存。
4. 总览默认用一张共享时间轴的甘特图展示所有方向泳道和其中的里程碑，也可切换「里程碑列表」。在甘特图中查看排期和实际投入，在方向摘要中查看最新进展与下一步计划。
5. 阶段成果由你核对并标记完成。Task 全部完成不会自动完成里程碑；持续型不显示总体完成率，可以暂停或结束跟踪。

方向和里程碑可以归档、恢复。归档保留历史，也不会自动完成或归档下属对象。迁移不会替你建立 KTLO、职业成长等真实方向，也不会推断旧任务的归属。

## 看时间安排和方向摘要

甘特图可以按周或按月查看，用「今天」和左右按钮移动时间窗口。所有方向共用一条时间横轴；方向左侧保留名称、期间投入和一行最新进展，里程碑以紧凑时间条展示名称、状态符号及空间允许时的工时。重叠排期分行，不重叠排期复用同一行；长标题不会额外撑高泳道。目标点、开放结束和视窗外延续如实表示。

鼠标悬停或键盘聚焦里程碑，可预览完整名称、日期、期间/累计投入和进展。Escape 关闭预览。短排期的色条仍严格对应日期，透明点击范围适当扩大且不遮住邻近条目的中心。

点击方向或里程碑，右侧打开详情与笔记面板，甘特图位置保留。方向的完整「最新进展」「下一步计划」、手工编辑、LLM 草稿和历史在这里集中查看；里程碑的「调整排期」也在面板中。关联 Notes 直接可见，点击单篇打开正文，或从「在 Notes 中查看」进入标签筛选。

LLM 先生成草稿，经审阅和手工采用才更新方向摘要；未保存文字在本次会话中暂存。概览的浏览、预览和筛选不改动 Note 正文。

无日期及视窗外里程碑以数量入口收起，展开后可以设置日期或定位。状态和归档放在「筛选」中；顶部区分统计期间的全部投入与当前显示里程碑的现有状态，计时说明可展开。时间条表示计划历时，不表示实际工时或完成百分比。

## 在 Notes 中键入标签筛选

Notes 主界面的搜索框同时支持全文文字和对象标签。例如输入 `#职业成长`，从候选中选择方向；继续输入 `#问题分析` 选择里程碑。已选择的标签显示为可删除的块，候选明确区分方向和里程碑。同名里程碑同时显示所属方向。

多个标签按「全部匹配（AND）」筛选，再与普通全文文字共同生效。方向标签包含直接引用方向及其下里程碑的笔记，同一篇只出现一次；已有 Task–Note 关联的派生来源保持原有规则。对象筛选在服务端搜索结果数量限制之前执行，较早的关联 Note 不会因为无关新笔记占满列表而被漏掉。

候选支持上下键、Enter 和点击选择；Escape 关闭候选且保留输入；搜索框为空时 Backspace 删除最后一个标签，也可点击标签上的删除按钮。中文输入法确认文字时不会提前选中候选。输入 `#` 但未选中时会提示正在选择；没有匹配项时保留原文字并提示修改，删除 `#` 后可恢复为普通全文搜索。筛选会保留在当前页面地址和客户端会话中，切换页面后回来仍可继续使用。

搜索标签只控制列表，不改写 Note 的正文、对象引用或当前编辑版本。编辑中的 Note 不会因为改变筛选条件被自动替换。

## 关联、投入与历史调整

Task 和 Note 元数据中的对象标签是稳定 ID 引用，与普通主题标签分开。一个 Note 可以关联多个方向和里程碑，并标明资料、成果、复盘或成长用途。改名后仍然可追踪；引用子里程碑的 Note 会在方向中汇总、去重，已有 Task–Note 链接也会显示派生来源。

实际投入只沿 `work_sessions → Task 主里程碑 → 方向` 汇总，相关引用和 Note 不重复计时。项目页与 Report 使用同一服务和工作日边界；未归属投入单独显示，点击可整理对应 Task。两个层级是同一份投入的两种分组，不应相加。

已有 Task 改归属会重新分类其全部历史投入。保存前显示影响预览，保存后可在没有后续冲突时撤销。里程碑换方向遵循同样规则；日志和原始计时时段不被搬动。若工作从此转向另一个目标，可以「在另一里程碑继续」建立新 Task 草稿并保留来源链接。

关闭调整窗口后，进入原里程碑或新里程碑底部的「变更历史与归属调整」，展开对应记录，核对前后目标并点击「撤销整次调整」。解除主归属后也可从原里程碑找回记录。批量调整会展示全部受影响 Task，确认后恢复整个批次；有后续关系变化时，系统会阻止撤销。

## 留下总结与成长记录

在详情中创建复盘 Note 或选择已有 Note。阶段型支持完成复盘；方向和持续型支持多次阶段回顾。Note 正文继续使用原来的 Notes 编辑器和版本保护。

标记里程碑完成与确认复盘是两件事，因此允许「已完成 · 待复盘」。确认时查看当前 Note 内容，保存一份内容版本和证据快照。以后修改或删除原 Note、改归属、移除用途标签，都不会改写已确认版本。里程碑重开后再次完成，对应新的完成事件和复盘状态。

## 使用 LLM 草稿

先在 Settings 配置 LLM，再从方向或里程碑详情选范围、覆盖预算并生成草稿。生成在后台执行，可以查看状态、取消或重试。原始资料、实际送入分析的片段、引用及覆盖缺口一并保留。

历史覆盖预算决定读取多少资料和最多调用几次；输出与推理预算是每次调用的输出上限，可选择 4,000、8,000 或 16,000 tokens。若提示输出额度耗尽，可以提高后重新生成；旧失败草稿和确认版本保留。提高历史覆盖范围不会自动提高每次调用的输出上限。

草稿提供观察、可能解释、反证或缺口，以及建议验证；工时和任务数量由服务端计算。长记录按来源分块，预算不足会显示遗漏范围。采纳时创建新 Note 或以版本校验追加已有 Note，之后仍由你决定如何编辑、是否确认复盘。原始资料变化后会提示证据陈旧，可以重新生成，或明确确认使用历史快照。

LLM 不自动改任务、完成目标或安排工作。没有配置 LLM 时，管理、关联、统计和手写复盘仍可使用。
