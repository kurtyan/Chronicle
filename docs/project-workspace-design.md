# 项目工作区：延续 Chronicle 的界面规则

2026-09-13 复核：本文描述上一轮控件与布局修复，尚不足以代表整体产品设计完成。当前问题、统一交互模型及产品验收基线见 [整体体验复核](project-workspace-product-review.md)。

## 目标

方向（Area）承载长期重点，里程碑（Milestone）承载可验证成果或持续跟踪事项。项目工作区帮助判断投入、进展和下一步。Task 的记录、计时与 Focus 工作流保持既有行为。

## 延续现有产品

依据 App、Board、Focus、Notes 和 NotePicker 的实际实现：固定图标导航、完整高度的工作区、独立滚动区域、紧凑工具栏、低对比边框、柔和背景和键盘优先。沿用既有颜色 token、字号层次和 Dialog，不添加一套独立的 dashboard 视觉语言。

- **概览**：标题和期间投入保持简短；一行工具栏承载搜索、方向与期间筛选。甘特图填满余下宽高，所有方向共用时间轴；里程碑重叠才增加轨道。留白由时间网格承接，单个方向不会为了填满屏幕而被拉高。
- **渐进展示**：时间条只保留名称、状态线索与投入。悬停/聚焦显示详情；点击打开右侧进展、下一步和关联 Notes。编辑与复盘在对应详情中进行。
- **详情**：大屏使用主内容和辅助侧栏；目标、任务、复盘与引用分组呈现，长文本在局部控制阅读宽度。
- **选择器**：统一的轻量搜索弹层，键入过滤，方向键浏览，Enter 选择，Escape 关闭并回到触发按钮；使用相同边框和背景。嵌套在编辑对话框内时，关闭选择器不应关闭整个表单。
- **Task 批量归属**：平时只有项目过滤入口与选择任务入口。进入选择模式后，显示数量、全选、清除和归属操作；任务行与复选框只改变选择。归属分为选择目标、预览历史投入变化、保存，保存后可撤销；沿用服务器的原子预览与版本校验。

## 语言与键盘

所有新增静态文案、状态、日期、数量、空态、错误回退、悬停及无障碍标签使用现有 i18n；用户写入的名称和笔记不自动翻译。Auto 跟随系统语言，显式语言设置优先。

新建回顾的模板及 AI 草稿也遵循当前语言。AI 草稿保存生成时的语言，重试、采用和备份恢复继续使用该语言；已有 Note、历史草稿及取证原文保持原样。

侧栏顺序与数字快捷键共用定义：⌘1–4 保持原有页面，⌘5 进入项目，⌘6 进入设置。项目总览支持 ⌘F 搜索、⌘N 新建里程碑；尚无方向时先创建方向。弹层遵循现有快捷键作用域。

从 Focus 使用侧栏或数字快捷键切页前，等待当前草稿保存；保存期间继续输入会再保存最新内容，连续切页以最后一次目标为准。保存失败时保留当前编辑器。此保护只覆盖上述应用导航入口，不包含浏览器历史和其他链接，也不会提交 Focus 进度或改变计时。

## 验收

英文与中文浏览器环境分别覆盖页面及弹层；在 1728×1117 和 2056×1329 验证宽高利用率、紧凑泳道及溢出；覆盖搜索选择、嵌套弹层、键盘导航、批量预览保存撤销、回顾版本与 Notes 引用。既有 Task、Focus、会话及 Notes 隔离回归使用独立数据库，避免操作日常数据。
