# 项目概览的信息层级重构

日期：2026-09-12。基于用户对上一轮概览密度和产品设计的反馈。

## 任务与取舍

概览用于判断工作组合：各方向投入多少、哪些里程碑并行、哪些成果已完成。前一版把方向详情和里程碑详情嵌进甘特图，导致单方向超过 200px、同一个时间条占 88px。调整目标是让排期成为视觉主体，并保留投入与完成状态这两个决策信号。

用户列举的悬停与操作位置是对设计意图的解释，不逐条当成界面规格。

## 信息分层

| 场景 | 直接提供的信息 | 交互 |
| --- | --- | --- |
| 扫视总体 | 方向名、期间投入、一行最新进展；里程碑名称、真实计划长度、状态符号、容得下时的简写工时 | 共享时间轴、方向泳道、真实日期重叠分轨 |
| 快速核对一个里程碑 | 完整名称、状态、计划日期、期间/累计投入、最新进展 | 悬停或键盘聚焦预览，Escape 关闭 |
| 阅读及管理一个对象 | 方向完整进展/下一步/摘要更新，或里程碑详细信息/排期入口；关联 Notes 直接可见 | 点击打开右侧面板，甘特图位置保留 |
| 处理低频事项 | 无日期目标、视窗外排期、归档筛选、计时口径 | 计数入口、可展开筛选或说明，避免占满主画布 |

单轨方向目标约 72px，额外重叠轨道约增加 36px。标题在短条中截断，不拉长真实排期，不因标题长制造额外轨道。目标点保持菱形；持续型保持开放端点。状态不只依赖颜色，完成和暂停有符号；Task 完成比例不代表里程碑验收完成，不在概览当作进度。

顶部收敛为标题、投入摘要及一组筛选/视图工具。甘特图只有自己的时间控制，移除重复标题、长说明与每个条目的常驻编辑按钮。常见筛选保持易达，低频过滤与计时口径可展开。

## 交互边界

- 悬停是可选快捷预览；键盘和点击同样可以得到信息，不能要求用户只能 hover。
- 预览只读，不生成 LLM 内容、不请求保存。完整动作只在选定对象后出现。
- 点击方向和里程碑后，Notes 仍直接可见，不再增加一层知识入口。
- 方向摘要仍是可编辑、可保留来源和历史的独立对象，不删字段、不自动覆盖。
- 投入与排期是两个口径：摘要/预览/面板沿用概览的统计期间，日期条不表示工时或完成百分比。
- 截图使用原隔离演示数据，与上一轮对照；验收包含真实客户端外观及 hover/focus、密度、日期分轨、Note 无写入检查。

## 验收结果

- Web/服务及 Tauri 前端重新构建成功，独立原生测试客户端已重新打包。未运行 release，也未发布或修改生产库。
- 最终 32 项集成及 WebKit 回归全部通过（30.4 秒）：9 项甘特图、3 项方向摘要、5 项原项目页面、9 项项目接口集成、6 项 Notes 标签筛选。
- 新增和更新的场景包含：单轨≤88px/双轨≤112px的真实元素几何、长标题不多占轨、单日真实宽度、按月短条中心分别可点击、hover/focus/Escape/Enter、累计列去重、筛选空态和重置、侧栏内打开摘要编辑器并保存后继续阅读 Notes、跨页零 Note 写入及版本保留。
- 初次构建发现当前 lucide 版本没有 Rows3，已使用现有 Rows。首次浏览器回归发现短时间条被按钮 padding 撑宽，修复真实条宽后保留原断言；没有降低断言来绕过失败。
- 独立产品审查还修复：累计期间重复列、箭头被误解为持续型、筛选计数时间口径不清、筛选空态误报、短条命中范围和左边界裁切提示。
- Computer Use 在最终原生客户端核对4方向/9里程碑全屏布局，键盘聚焦显示预览，Enter 打开里程碑侧栏，点击方向显示完整摘要/下一步/关联 Notes。鼠标 hover 与短条精确点击由 WebKit 自动用例验证；不将键盘预览描述成原生鼠标悬停验收。
- 最终截图另经独立视觉复查，未发现可读性或密度阻断。

截图均为真实客户端，使用隔离的 `.dev-data/project-manual-ZGKikS` 合成数据；新增 KTLO、工程质量及4个里程碑只用于多方向密度验证，不代表用户真实安排，新增对象没有伪造实际工时。原有6.5小时亦为之前明确标注的合成 Session。没有调用真实 LLM。
